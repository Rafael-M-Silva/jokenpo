# jokenpo

Jogo de pedra, papel e tesoura no navegador desenvolvido com JavaScript.

Projeto desenvolvido para fins educacionais.

## Onde está o código

Página principal em `index.html`; estilos em `css/style.css`; interação em `main.js`.

**Tecnologias:** `CSS`, `HTML`, `JavaScript`.

## Visualizar localmente

Use um servidor HTTP local para abrir `index.html`.
